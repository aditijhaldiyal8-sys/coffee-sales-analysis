# COFFEE SHOP SALES ANALYSIS
Analysis of Coffee Shop Sales in Sql using PostgreSQL

# Highlights
-Cleaned and analyzed Coffee Shop Sales dataset in PostgreSql
-Performed advanced SQL queries
-Built an interactive Powerbi Dashboard
-Created DAX measures 
-Identified key insights using data visualisation

This project analyzes a coffee shop sales using postgreSQL and Powerbi. It covers insights such as revenue, store performance, product performance etc. 
This project includes 
-Sql data analysis 
-Exploratory Data Analysis (EDA)
-DAX measures
-Interactive PowerBi dashboard.

#Tools used:-
-*PostgreSql*:- Data cleaning and sql analysis
-*Powerbi*:- Dashboard creation and data visualisation
-*DAX*:- creating calculated measures and KPIs
